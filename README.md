📚 Comptinou

Comptinou est une application Android développée dans le cadre d’un projet scolaire par une équipe de quatre étudiants. Ce projet a été réalisé avec Java et Kotlin sous Android Studio.

✨ Description

Comptinou permet de créer des histoires personnalisées pour les enfants, en intégrant des éléments comme leur prénom, leurs goûts ou encore leurs personnages préférés.
L’objectif est d’offrir une expérience immersive, ludique et éducative, en rendant chaque histoire unique.

⚙️ Fonctionnalités principales
	•	✏️ Choix et personnalisation d’histoires
	•	📖 Lecture interactive sur smartphone ou tablette
	•	🎨 Interface simple et adaptée aux jeunes enfants (couleurs pastels)

🛠️ Technologies utilisées
	•	Langages : Java, Kotlin
	•	Environnement de développement : Android Studio
	•	Plateforme ciblée : Android
